# 数据收发

数据收发是 ComAssistant 的核心工作流。串口使用文本、HEX、过滤等接收标签页；TCP、UDP 和 HID 使用各自的专用通信工作台。

## 发送数据

### 文本发送

1. 在当前工作台发送区输入文本。
2. 根据设备协议选择是否追加换行。
3. 点击发送按钮。

### HEX 发送

1. 勾选 **HEX发送**。
2. 输入十六进制数据，例如 `AA 55 01 02`。
3. 点击 **HEX格式化** 可规范化输入。
4. 点击发送按钮。

## 接收数据

| 显示方式 | 适用场景 |
|----------|----------|
| 文本显示 | AT 指令、日志、ASCII 协议 |
| HEX 显示 | 二进制帧、Modbus、私有协议 |
| 过滤视图 | 快速定位 `ERROR`、`OK`、关键帧 |
| 数据表格 | 结构化追踪收发记录和解析值 |

## 串口显示模式

工具栏右侧 **模式** 只作用于串口类型：

| 模式 | 说明 |
|------|------|
| 串口模式 | 常规文本/HEX 收发 |
| 终端模式 | 类终端交互，适合 Linux、RTOS Shell |
| 帧模式 | 按帧组织显示，适合二进制协议观察 |
| 调试模式 | 带方向、时间戳和记录结构的调试视图 |

## 数据保存

- 使用 **文件 → 导出数据** 打开增强导出对话框，导出最近的结构化 RX/TX 历史。格式支持 TXT、CSV、HTML、JSON、XML、二进制和十六进制转储，可按方向、时间和内容正则过滤。
- 真实保存文件时，增强导出会按匹配记录流式写入目标文件，不再先复制全部过滤结果或拼接完整导出内容；预览仍限制为少量记录，适合先确认格式。
- 使用 **文件 → 保存会话** 保存当前连接配置、显示状态和部分历史数据。
- 数据表格视图可导出结构化 CSV，适合后续分析。

## 使用建议

- 调试二进制协议时，优先使用 HEX 显示和数据表格视图。
- 长时间高频接收时，控制接收缓存、导出历史和绘图窗口数量，避免 UI 压力过大。主窗口导出历史默认只保留最近数据，清空当前数据会释放导出历史容量。
- 数据分窗用于辅助观察匹配数据，会按行数和字符数保留最近内容；遇到无换行长流时会删除最早文本并保留最新文本，分窗导出也只导出当前保留内容。
- 数据表格用于结构化追踪最近收发记录；点击 **清空** 会同时清除表格行、待刷新记录和可重建缓存容量，后续新记录会从序号 1 重新开始。
- 如果要保留完整调试过程，建议配合会话保存和导出功能使用。
