# 主题定制

ComAssistant 支持明亮和暗黑主题，并会尽量让内置帮助、工具栏和主要工作台保持一致的视觉风格。

## 切换主题

1. 点击侧边栏或工具栏上的主题按钮。
2. 在明亮主题和暗黑主题之间切换。
3. 主题选择会保存到本地配置，下次启动自动恢复。

## 界面一致性

v1.8.0 之后的主题会同时覆盖主窗口、绘图窗口、脚本编辑器、文件传输、数据导出、设置、工具箱、会话恢复、数据分窗配置、临时设置弹窗、右键菜单和消息提示框。

主题使用更统一的桌面工具视觉层级：浅色主题以冷白、石板灰和专业蓝为主，暗色主题沿用原有 Apple 深色背景（`#1c1c1e` / `#2c2c2e`），并保持高对比文本。分组框会显示为清晰面板，输入框有统一焦点描边，默认按钮、危险按钮和禁用按钮会使用不同状态，便于在复杂弹窗里快速识别主要操作。

设置、导出、文件传输、协议配置等表单窗口会为下拉框、字体选择框和带单位后缀的数值框预留稳定高度与宽度，避免出现文字显示不全、单位被裁剪或控件互相遮挡。

## 语言切换

应用支持中文和英文界面。切换语言后，主窗口、菜单、工具栏、对话框和内置帮助中的主要文案会重新翻译。

## 高分屏建议

- Windows 缩放比例较高时，建议保持系统默认 DPI 设置。
- 如果文本显示过大或过小，优先调整系统缩放或应用字体，而不是修改窗口布局文件。

## 帮助文档主题

内置帮助文档带有明暗主题样式变量，会随系统或应用主题保持可读性。若发现某个帮助页面颜色不一致，应同步修复 `resources/help/*.html`。

## 后续可优化方向

- 增加主题配置导入导出。
- 支持自定义字体、字号和代码块配色。
- 为高频调试场景提供更紧凑的工作台布局。
