# 主题定制

ComAssistant 支持明亮和暗黑主题，并会尽量让内置帮助、工具栏和主要工作台保持一致的视觉风格。

## 切换主题

1. 点击侧边栏或工具栏上的主题按钮。
2. 在明亮主题和暗黑主题之间切换。
3. 主题选择会保存到本地配置，下次启动自动恢复。

## 语言切换

应用支持中文和英文界面。切换语言后，主窗口、菜单、工具栏、对话框和内置帮助中的主要文案会重新翻译。

## 高分屏建议

- Windows 缩放比例较高时，建议保持系统默认 DPI 设置。
- 如果文本显示过大或过小，优先调整系统缩放或应用字体，而不是修改窗口布局文件。

## 帮助文档主题

内置帮助文档带有明暗主题样式变量，会随系统或应用主题保持可读性。若发现某个帮助页面颜色不一致，应同步修复 `resources/help/*.html`。

## 后续可优化方向

- 增加主题配置导入导出。
- 支持自定义字体、字号和代码块配色。
- 为高频调试场景提供更紧凑的工作台布局。
