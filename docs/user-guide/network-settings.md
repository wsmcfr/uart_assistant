# 网络设置

ComAssistant 支持 TCP 客户端、TCP 服务器和 UDP 三类网络通信工作台。网络类型通过工具栏 **类型** 切换，每种类型都有独立的主体界面。

## TCP 客户端

TCP 客户端用于连接已经启动的服务器或网络设备。

1. 在工具栏 **类型** 中选择 **TCP客户端**。
2. 在工作台填写服务器 IP、端口和连接超时。
3. 如果需要断线后自动连接，勾选 **断开后自动重连** 并设置重连间隔。
4. 点击工具栏 **连接**。
5. 在底部发送区输入文本或 HEX 数据。

## TCP 服务器

TCP 服务器用于监听本机端口，等待外部客户端连接。

1. 在工具栏 **类型** 中选择 **TCP服务器**。
2. 设置监听端口和最大连接数。
3. 点击 **启动服务**。
4. 客户端连接后会出现在目标客户端列表。
5. 可选择向单个客户端发送，也可点击广播发送给全部客户端。

## UDP

UDP 适合无连接数据报调试，例如本地广播、嵌入式网口数据上报或简单遥测。

1. 在工具栏 **类型** 中选择 **UDP**。
2. 设置本地端口、目标 IP 和目标端口。
3. 点击 **绑定端口**。
4. 收到数据后，发送方会加入 **最近远端**，可快速切换目标。
5. 需要广播时勾选 **广播发送**。

## 日志和发送辅助

| 功能 | 说明 |
|------|------|
| 自动滚动 | 收发日志自动滚动到最新位置 |
| 复制 | 复制当前工作台日志内容 |
| 清空 | 清空当前工作台日志 |
| HEX格式化 | 将 `0x0a bb c` 规范化为 `0A BB 0C` |
| Ctrl+Enter | 在 TCP/UDP 发送输入框中快速发送 |

## 排查建议

- TCP 客户端连接失败时，先确认服务器 IP、端口、防火墙和目标程序监听状态。
- TCP 服务器无法启动时，检查端口是否已被其他程序占用。
- UDP 收不到数据时，检查本地端口、防火墙、目标 IP 和广播网段。
