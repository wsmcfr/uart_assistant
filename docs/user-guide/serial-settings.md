# 串口设置

本章节说明串口工作台的常用连接参数。串口参数必须与下位机、USB 转串口模块或目标设备固件保持一致，否则会出现乱码、无响应或偶发丢包。

## 基本步骤

1. 在工具栏 **类型** 中选择 **串口**。
2. 点击刷新按钮，重新扫描当前系统可见的 COM 端口。
3. 选择目标端口，例如 `COM3`。
4. 设置波特率、数据位、停止位、校验位和流控。
5. 点击 **打开串口**。

## 参数说明

| 参数 | 作用 | 常用值 |
|------|------|--------|
| 端口 | 选择实际连接的串口设备 | `COM3`、`COM5` |
| 波特率 | 决定串口传输速度 | `115200`、`921600` |
| 数据位 | 每帧数据位数 | `8` |
| 停止位 | 每帧结束位 | `1` |
| 校验位 | 用于基础错误检测 | `None` |
| 流控 | 控制发送节奏 | `None` 或 `Hardware (RTS/CTS)` |

## 高波特率建议

- 先用 `115200` 验证基本收发，再逐步提升到 `921600` 或更高。
- 如果设备端处理速度有限，发送大块数据时优先使用文件发送中心的包间隔配置。
- 高速收发时建议关闭不必要的绘图窗口或降低绘图显示点数。

## 常见问题

| 现象 | 可能原因 | 处理方式 |
|------|----------|----------|
| 找不到端口 | 设备未插入、驱动未安装或端口被系统隐藏 | 重新插拔设备，安装驱动后点击刷新 |
| 打开失败 | 端口被其他程序占用 | 关闭其他串口工具后重试 |
| 显示乱码 | 波特率或编码不一致 | 核对设备固件串口参数 |
| 偶发丢包 | 下位机缓存或处理速度不足 | 降低发送速度，启用更大的包间隔 |
