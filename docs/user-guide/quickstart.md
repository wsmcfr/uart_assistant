# 快速入门

本章节将帮助您在 5 分钟内开始使用 ComAssistant。

## 第一步：启动程序

双击桌面上的 ComAssistant 图标，或从开始菜单中启动程序。

## 第二步：建立连接

工具栏左上角的 **类型** 用于切换通信工作台：串口、TCP客户端、TCP服务器、UDP 和 HID 会显示不同的专用界面。右上角的 **模式** 只用于串口工作台的数据展示方式；切换到 TCP、UDP 或 HID 后，主体区域会变成对应的通信调试界面。

### 串口连接

1. **选择类型**: 在工具栏"类型"下拉框中选择"串口"
2. **选择串口**: 在端口下拉框中选择您的串口设备（如 COM3）
3. **设置波特率**: 选择合适的波特率（常用 115200）
4. **打开连接**: 点击"打开串口"按钮

连接成功后，状态栏会显示"已连接: COMx"。

### TCP 客户端

1. **选择类型**: 在工具栏"类型"下拉框中选择"TCP客户端"
2. **填写服务器**: 在 TCP 客户端工作台填写服务器 IP、端口和连接超时
3. **自动重连**: 需要断线重连时勾选"断开后自动重连"并设置重连间隔
4. **建立连接**: 点击工具栏"连接"按钮
5. **收发数据**: 在工作台底部发送区输入文本或 HEX，网络流收发日志会显示在中间区域
6. **日志工具**: 可使用"自动滚动"、"复制"和"清空"管理网络流日志

### TCP 服务器

1. **选择类型**: 在工具栏"类型"下拉框中选择"TCP服务器"
2. **设置监听**: 在 TCP 服务器工作台设置监听端口和最大连接数
3. **启动服务**: 点击工具栏"启动服务"按钮
4. **管理客户端**: 客户端连接后会出现在目标客户端列表
5. **断开客户端**: 选中客户端后可点击"断开选中"主动关闭该连接
6. **发送数据**: 可选择"发送到客户端"或"广播"发送给所有客户端

### UDP

1. **选择类型**: 在工具栏"类型"下拉框中选择"UDP"
2. **设置端点**: 在 UDP 工作台设置本地端口、目标 IP 和目标端口
3. **绑定端口**: 点击工具栏"绑定端口"按钮
4. **选择远端**: 收到数据报后，发送方会加入"最近远端"列表，可一键切换目标
5. **清理远端**: 最近远端列表可通过"清空最近"重置
6. **发送数据报**: 输入文本或 HEX 后点击"发送数据报"，需要广播时勾选"广播发送"

### HID 连接

1. **选择类型**: 在工具栏"类型"下拉框中选择"HID"
2. **刷新设备**: 点击刷新按钮扫描当前系统可见的 HID 设备
3. **选择设备**: 在设备下拉框中选择目标设备，列表会显示 VID、PID 与接口号
4. **设置 Report**: 在 HID Report 工作台确认 Input、Output、Feature 长度和 Report ID
5. **打开连接**: 点击"打开 HID"按钮
6. **调试 Report**: 使用 Output payload 发送输出报告，使用 Set Feature/Get Feature 调试 Feature Report
7. **查看预览**: Output/Feature 输入变化时会显示完整 Report 预览；payload 超过可用长度时会显示截断提示

HID 模式不使用波特率；如果下拉框显示"HID 后端未启用"，说明当前本地构建没有找到 hidapi，需要使用发布构建或通过 vcpkg/toolchain 重新配置构建。HID 不是普通文本流，Report 长度、Report ID 和设备协议必须与厂商文档一致。

## 第三步：发送数据

### 串口/TCP/UDP 文本发送
1. 在底部发送区输入文本
2. TCP/UDP 工作台可勾选"追加换行"自动在文本末尾加入 `\n`
3. 点击发送按钮；TCP/UDP 工作台也可在发送输入框按 `Ctrl+Enter` 快速发送

### 串口/TCP/UDP HEX 发送
1. 勾选"HEX发送"选项
2. 输入十六进制数据（如 `AA BB CC DD`）
3. 可点击"HEX格式化"把 `0x0a bb c` 规范化为 `0A BB 0C`
4. 点击发送按钮；TCP/UDP 工作台也可按 `Ctrl+Enter`

### HID Report 发送
1. 在 HID Report 工作台填写 Output payload 或 Feature payload
2. Output Report 会按 Output Report ID、Output 长度和"首字节为长度"选项构造
3. Feature Report 使用独立的 Feature Report ID 和 Feature 长度
4. Output/Feature 区域会显示 Report 预览、payload 字节数和截断提示
5. 可点击"HEX格式化"规范化 payload，报告历史会记录方向、类型、长度、HEX 和文本摘要

## 第四步：接收数据

串口接收到的数据会自动显示在接收区：

- **文本标签页**: 显示 ASCII 文本
- **十六进制标签页**: 显示 HEX 格式
- **过滤标签页**: 根据关键词过滤显示

TCP客户端、TCP服务器、UDP 和 HID 会在各自工作台显示专用收发日志。网络工作台日志支持自动滚动、复制和清空；HID 输入报告会按"接收时移除输入 Report ID"选项归一化后进入历史。

### 接收选项
- **时间戳**: 显示接收时间
- **自动滚动**: 自动滚动到最新数据
- **HEX显示**: 切换十六进制显示

## 第五步：保存数据

### 导出数据
1. 点击菜单 **文件 → 导出数据**
2. 选择导出格式（TXT、CSV、HTML、JSON）
3. 选择保存位置

### 保存会话
1. 点击菜单 **文件 → 保存会话**
2. 选择保存位置
3. 下次可通过 **文件 → 加载会话** 恢复

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开/关闭当前连接 |
| Ctrl+L | 清空接收区 |
| Ctrl+E | 导出数据 |
| Ctrl+Enter | 在 TCP/UDP 发送输入框中快速发送 |
| F1 | 打开帮助 |
