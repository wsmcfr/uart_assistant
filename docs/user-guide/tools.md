# 工具箱

工具箱提供常用调试辅助功能，适合在编写协议帧、检查校验值或转换数据格式时使用。

## 打开方式

通过菜单或工具入口打开 **工具箱**。

## 校验和

校验和页可对输入数据计算常用校验值。

支持的类型包括：

- CRC-16 Modbus
- CRC-16 CCITT
- CRC-16 CCITT-FALSE
- CRC-16 XMODEM
- CRC-32
- CRC-8
- CRC-8 MAXIM
- XOR
- SUM
- LRC
- BCC

## 进制与字节序转换

| 功能 | 说明 |
|------|------|
| 进制转换 | 在十进制、十六进制、二进制、八进制之间转换 |
| 字节反转 | 将 `01 02 03 04` 转为 `04 03 02 01` |
| 16 位交换 | 按 16 位数据宽度交换字节 |
| 32 位交换 | 按 32 位数据宽度交换字节 |
| IEEE754 | Float 与 HEX 互转，支持大小端设置 |

## 编码工具

编码页提供 Base64、URL 编码、转义序列处理和字符编码转换，适合调试文本协议、HTTP 风格参数或混合转义字符串。

编码页会为输入框、输出框、编码下拉框和转换按钮保留稳定尺寸。窗口较小时可通过页内滚动查看下方字符编码转换区域，避免底部控件被压缩、文字被裁剪或按钮被遮挡。

## 使用建议

- 发送二进制协议前，先在工具箱计算校验值并确认字节序。
- 与下位机联调时，把工具箱结果和设备端计算结果对照，可快速定位端序或多项式不一致问题。
- 工具箱只做离线计算，不会自动修改发送区内容。
