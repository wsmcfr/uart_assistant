# 通信工作台精细化打磨设计

## 背景

上一轮已经把 TCP客户端、TCP服务器、UDP 和 HID 从串口式收发界面中拆出来，形成了专用通信工作台。但当前第一版仍偏基础表单：参数区、日志区、发送区都有了，视觉层次、日志操作、发送辅助、输入校验和 HID Report 预览还不够像一个长期可用的调试工具。

本轮目标是在不推翻现有架构的前提下，把这些工作台打磨成更专业、更顺手的调试界面。

## 目标

| 方向 | 目标 |
|---|---|
| 视觉层次 | 参数区、状态区、日志区、发送区更清楚，避免大块表单堆叠 |
| 日志可用性 | 提供清空、复制、自动滚动；日志格式包含方向、长度、HEX 和文本摘要 |
| 发送效率 | 支持 Ctrl+Enter 发送、追加换行、HEX 格式化、输入长度提示 |
| 目标管理 | TCP服务器更清楚地管理客户端；UDP 最近远端可一键使用 |
| HID Report | Output/Feature 发送前可看到完整 Report 预览，超长 payload 有提示 |

## 非目标

| 项目 | 说明 |
|---|---|
| 主题系统重写 | 不在本轮改全局主题，只使用 Qt 控件和轻量样式 |
| 多连接模型重构 | TCP服务器仍使用现有通信对象的客户端管理能力 |
| 协议级解析器 | 不解释厂商私有 HID 或 TCP/UDP payload 结构 |

## 设计方案

### 共享工作台能力

新增或强化 `CommunicationWorkspaceWidget` 的共享能力：

| 能力 | 说明 |
|---|---|
| payload 解析 | 保持文本/HEX 输入兼容，提供 HEX 规范化 |
| 日志格式 | 统一为时间、方向、类型、字节数、HEX、文本摘要 |
| 日志操作 | 工作台可清空日志、复制日志、自动滚动到底部 |
| 快捷发送 | 发送输入框支持 Ctrl+Enter 触发发送 |

### TCP客户端

| 区域 | 打磨 |
|---|---|
| 状态摘要 | 显示连接状态、目标地址、自动重连状态 |
| 参数区 | IP、端口、超时、重连间隔保持紧凑 |
| 发送区 | 增加追加换行、HEX格式化、字节数提示 |

### TCP服务器

| 区域 | 打磨 |
|---|---|
| 状态摘要 | 显示监听端口、客户端数量 |
| 客户端区 | 保留目标下拉，同时显示客户端数量和断开选中入口 |
| 发送区 | 单发和广播按钮更明确，空客户端时禁用单发 |

### UDP

| 区域 | 打磨 |
|---|---|
| 状态摘要 | 显示本地端口、目标地址、广播状态 |
| 远端管理 | 最近远端选择后同步目标，提供清空最近远端 |
| 发送区 | 广播时目标提示固定为 `255.255.255.255`，保留端口 |

### HID Report

| 区域 | 打磨 |
|---|---|
| 参数摘要 | 设备信息和 Report 参数更紧凑 |
| Report 预览 | Output 和 Feature 输入变化时预览完整报告 HEX |
| 输入保护 | payload 超过报告可用长度时显示截断提示 |
| 历史 | 记录 Input、Output payload、Feature Set/Get 的完整方向和长度 |

## 测试策略

| 测试 | 内容 |
|---|---|
| Widget 测试 | Ctrl+Enter 发送、HEX 格式化、日志清空/复制、自动滚动开关 |
| HID 测试 | Output/Feature 预览和超长提示 |
| 回归测试 | 保持现有工作台配置读写、发送信号测试通过 |
| 构建验证 | 使用 `D:\comassistant\build_release` 完整构建和 `ctest` |
