# 通信类型专用工作台设计

## 背景

当前主界面左上角“类型”包含串口、TCP客户端、TCP服务器、UDP、HID，但主体区域仍主要复用串口调试界面。串口界面适合文本流与 AT 命令调试；TCP、UDP、HID 的连接语义、目标选择、状态反馈与发送对象不同，继续套用串口界面会让用户误以为这些类型只是“换了连接入口”。

本设计将左上“类型”明确为通信后端工作台切换入口。串口保留现有串口工作区；TCP客户端、TCP服务器、UDP、HID 新增专用工作台。右上“模式”继续作为串口数据展示模式，非串口类型隐藏该显示模式切换，避免把“显示模式”和“通信类型”混淆。

## 目标

| 类型 | 专用界面目标 |
|---|---|
| TCP客户端 | 展示服务器地址、连接状态、自动重连参数、网络流收发日志 |
| TCP服务器 | 展示监听状态、客户端列表，支持指定客户端发送和广播发送 |
| UDP | 展示本地绑定、目标地址、最近远端，支持单播和广播发送 |
| HID | 展示 HID 设备信息、Report 参数、Input/Output/Feature 报告收发和报告历史 |

## 非目标

| 项目 | 说明 |
|---|---|
| 多连接会话重构 | 本次仍沿用现有 `ICommunication` 单连接模型 |
| 完整协议编辑器 | 专用工作台只负责通信层调试，不替代协议解析、绘图、脚本等功能 |
| 厂商私有 HID 协议识别 | HID 工作台提供 Report 级调试能力，不猜测厂商协议字段含义 |

## 架构设计

主窗口新增通信工作台栈：

| 层级 | 职责 |
|---|---|
| `MainWindow` | 保留类型选择、连接按钮、通信对象创建；根据通信类型切换工作台 |
| 串口工作台 | 复用现有 `m_modeStack` 和 `SerialModeWidget` 等显示模式组件 |
| 网络工作台 | 新增 TCP客户端、TCP服务器、UDP 三个 QWidget，提供对应配置、状态、日志、发送入口 |
| HID 工作台 | 新增 HID Report QWidget，管理 Report 参数、输入/输出/Feature 调试与历史 |
| `HidReportCodec` | 新增纯逻辑类，负责 HID 输出/Feature 报告构造和输入报告归一化，便于单元测试 |

## 数据流

| 操作 | 数据流 |
|---|---|
| 切换通信类型 | `onCommTypeChanged()` 更新 `m_currentCommType`，刷新顶部控件，并切换通信工作台 |
| 打开连接 | 主窗口先从当前工作台读取配置，再创建对应 `ICommunication` |
| 接收数据 | 主窗口继续接收 `ICommunication::dataReceived`，同时路由到当前通信工作台；串口类型仍路由到当前显示模式 |
| 发送数据 | 各工作台发出发送请求，主窗口根据通信对象写入；TCP服务器和 UDP 可走专用目标发送 |
| 状态变化 | 主窗口同步顶部按钮、状态栏和当前工作台连接状态 |

## HID Report 细节

| 能力 | 设计 |
|---|---|
| 设备信息 | 展示名称、VID、PID、接口、Usage Page、Usage |
| 输出报告 | 使用 Output Report 长度、Report ID、首字节长度选项构造报告 |
| Feature 报告 | 新增 Feature Report 长度和 Report ID 配置，支持 Set Feature 与 Get Feature |
| 输入报告 | 按输入报告长度接收，支持移除输入 Report ID |
| 历史 | 记录方向、类型、时间、长度、HEX 内容，便于对照设备协议 |

## 错误处理

| 场景 | 处理 |
|---|---|
| 未连接发送 | 工作台保留发送按钮但主窗口拒绝写入，并在状态栏提示 |
| HID 后端未启用 | HID 设备列表和工作台显示明确状态，不隐藏入口 |
| TCP服务器无客户端 | 广播发送返回 0 时保留日志，不伪造成功 |
| UDP 目标非法 | 工作台侧限制端口范围，主窗口发送前校验 IP/端口 |
