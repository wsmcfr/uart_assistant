快速入门 Quick Start

1. 建立连接 / Connection

中文：工具栏"类型"会切换通信工作台；串口、TCP客户端、TCP服务器、UDP 和 HID 都有各自的主体界面。右上"模式"只用于串口显示模式。

English: The toolbar "Type" dropdown switches communication workspaces. Serial, TCP Client, TCP Server, UDP and HID each have their own main workspace. The "Mode" dropdown is only for serial display modes.

串口连接 / Serial Connection

中文：

  1. 在工具栏"类型"中选择"串口"
  2. 在工具栏选择串口端口（如 COM3）
  3. 选择波特率（默认 115200）
  4. 点击"打开串口"按钮

English:

  1. Select "Serial" in the toolbar "Type" dropdown
  2. Select serial port in toolbar (e.g., COM3)
  3. Select baud rate (default 115200)
  4. Click "Open Port" button

TCP客户端 / TCP Client

  1. 选择"TCP客户端"，在工作台填写服务器 IP、端口和连接超时
  2. 需要时启用自动重连并设置重连间隔
  3. 点击工具栏"连接"，在网络流日志中查看收发数据
  4. 使用"自动滚动"、"复制"、"清空"管理日志，发送区支持 HEX格式化 和 Ctrl+Enter
  1. Select "TCP Client", then enter server IP, port and timeout in the workspace
  2. Enable auto reconnect when needed and set the reconnect interval
  3. Click "Connect" and inspect data in the network stream log
  4. Use auto scroll, copy and clear log tools; the send area supports HEX formatting and Ctrl+Enter

TCP服务器 / TCP Server

  1. 选择"TCP服务器"，设置监听端口和最大连接数
  2. 点击"启动服务"，客户端连接后会出现在目标客户端列表
  3. 可向指定客户端发送，也可广播给全部客户端
  4. 选中客户端后可点击"断开选中"，日志工具同样支持自动滚动、复制和清空
  1. Select "TCP Server", set listen port and max connections
  2. Click "Start Service"; connected clients appear in the target list
  3. Send to a selected client or broadcast to all clients
  4. Select a client and click "Disconnect Selected"; log tools also support auto scroll, copy and clear

UDP / UDP

  1. 选择"UDP"，设置本地端口、目标 IP 和目标端口
  2. 点击"绑定端口"，收到数据报后可从"最近远端"快速切换目标
  3. 最近远端可通过"清空最近"重置，需要广播时勾选"广播发送"
  4. 发送区支持 HEX格式化、追加换行、字节数提示和 Ctrl+Enter
  1. Select "UDP", set local port, target IP and target port
  2. Click "Bind Port"; recent senders can be selected as targets
  3. Clear recent remotes with "Clear Recent"; check "Broadcast" when broadcast datagrams are required
  4. The send area supports HEX formatting, append newline, byte count and Ctrl+Enter

HID 连接 / HID Connection

中文：

  1. 在工具栏"类型"中选择"HID"
  2. 点击刷新按钮扫描当前系统可见的 HID 设备
  3. 在设备下拉框中选择目标设备（显示名称包含 VID、PID 与接口号）
  4. 在 HID Report 工作台确认 Input、Output、Feature 长度和 Report ID
  5. 点击"打开 HID"按钮
  6. 使用 Output payload、Set Feature 和 Get Feature 调试报告
  7. 查看 Report 预览、payload 字节数和截断提示，发送前确认最终 HEX

English:

  1. Select "HID" in the toolbar "Type" dropdown
  2. Click refresh to scan visible HID devices
  3. Select the target device from the device dropdown (VID, PID and interface number are shown)
  4. Confirm Input, Output, Feature lengths and Report IDs in the HID Report workspace
  5. Click "Open HID" button
  6. Debug reports with Output payload, Set Feature and Get Feature
  7. Check Report previews, payload byte counts and truncation warnings before sending
💡 提示 / Tip: 连接前请确保端口或 HID 设备未被其他程序占用。HID 需要发布构建或已安装 hidapi 的本地构建支持，且 Report 长度和 Report ID 必须符合设备协议。
Make sure the port or HID device is not occupied before connecting. HID requires hidapi support, and Report length / Report ID must match the device protocol.

中文：HID 打开后，Input 轮询、Output 写入和 Feature Report 操作会进入后台 worker 线程，并按同一设备句柄串行执行；关闭 HID 时会先释放 worker 中的设备句柄。

English: After HID is opened, Input polling, Output writes and Feature Report operations run in a background worker thread and are serialized on the same device handle. Closing HID releases the handle in the worker first.

2. 发送数据 / Send Data

中文：在当前通信工作台的发送区输入数据并点击发送。TCP服务器可选择指定客户端或广播；UDP 可选择目标远端；HID 使用 Report 发送按钮。

English: Enter data in the current communication workspace and send. TCP Server can send to a selected client or broadcast; UDP can choose the remote target; HID uses report buttons.

  • 文本模式 / Text Mode: 直接输入文本 / Enter text directly
  • HEX模式 / HEX Mode: 输入十六进制（如 AA BB CC）/ Enter hexadecimal (e.g., AA BB CC)
  • HEX格式化 / HEX Format: 将 0x0a bb c 规范化为 0A BB 0C / Normalize input such as 0x0a bb c to 0A BB 0C
  • 快捷发送 / Quick Send: TCP/UDP 发送输入框支持 Ctrl+Enter / TCP/UDP send editors support Ctrl+Enter
  • HID Report: Output、Set Feature、Get Feature 会显示 Report 预览并记录方向、类型、长度和 HEX 内容 / Output, Set Feature and Get Feature show Report previews and record direction, type, length and HEX content

发送文件 / Send File

中文：工具栏的 发送文件 按钮可打开文件发送中心，适合发送 Keil/GD32 工程生成的 .bin、.hex 或其他文件。

English: Use the Send File toolbar button to open the file transfer center for .bin, .hex or other files.

  • 裸流分块 / Raw Chunks: 按指定“每包字节”和“包间隔”直接发送文件内容，适合 MCU 程序自行顺序接收。
  • XMODEM/YMODEM: 使用标准握手协议，适合会返回 C、NAK、ACK 的 Bootloader。
  • 自定义 OTA / Custom OTA: 发送文件头、分块数据和结束包，可选择等待 ACK、设置超时和重试。
  • 流式发送 / Streaming: 裸流和自定义 OTA 会按块读取文件，并等待本地发送队列确认后再推进下一块，适合较大的固件文件。
  • 可靠状态 / Reliable State: 文件传输会区分传输中、已暂停、正在取消、已取消、已完成和失败状态；失败时保留本地发送、连接或 ACK 超时等错误原因。
⚠️ 注意 / Warning: 发送固件前请确认串口已打开、设备已进入接收或 Bootloader 状态，并按设备处理能力设置块大小和包间隔；如果队列拒绝、写入失败或连接断开，当前文件传输会停止并显示失败原因。
Before firmware transfer, make sure the port is open and the device is ready. Choose block size and interval according to device capacity. If the queue rejects data, writing fails or the connection drops, the transfer stops with the failure reason.

示例 / Examples:

文本发送 / Text Send:

Hello World

HEX发送 / HEX Send:

AA 55 01 02 03 04

3. 接收数据 / Receive Data

中文：串口数据会显示在接收区标签页；TCP、UDP 和 HID 数据会显示在对应工作台日志或报告历史中。

English: Serial data appears in receive tabs; TCP, UDP and HID data appears in the corresponding workspace log or report history.

  • 文本标签 / Text Tab: 显示文本格式 / Display text format
  • 十六进制标签 / Hex Tab: 显示HEX格式 / Display HEX format
  • 过滤标签 / Filter Tab: 根据关键词过滤 / Filter by keywords

接收协议 / Receive Protocol

中文：通过 工具 -> 接收协议 选择当前接收解析器。Raw 直接显示原始数据，Lua Script 会按稳定协议 ID lua.script 调用脚本入口 process(data, context)。

English: Use Tools -> Receive Protocol to select the current receive parser. Raw displays raw data, while Lua Script uses the stable protocol ID lua.script and calls process(data, context).

中文：选择 Lua 后，可通过 工具 -> 协议配置... 在多行 scriptSource 编辑器中编写脚本；字段错误会显示在对应字段下方，配置随会话保存并可恢复。运行时错误会显示在状态栏，也可通过 工具 -> 协议诊断... 查看最近错误和诊断 JSON。

English: After selecting Lua, open Tools -> Protocol Config... to edit the multiline scriptSource. Field errors are shown next to the related field, and the config is saved and restored with sessions. Runtime errors appear in the status bar and are available from Tools -> Protocol Diagnostics....

中文：旧版 绘图协议 菜单仍只用于 TEXT、STAMP、CSV 和 JustFloat 等绘图协议。

English: The legacy Plot Protocol menu remains dedicated to plotting protocols such as TEXT, STAMP, CSV and JustFloat.

4. 常用功能 / Common Features

时间戳 / Timestamp

勾选"时间戳"选项，每行数据前会显示时间。
Check "Timestamp" option to show time before each line.

自动滚动 / Auto Scroll

勾选"自动滚动"，串口接收区或网络工作台日志会自动滚动到最新数据；关闭后可停留在历史位置对照旧数据。
Check "Auto Scroll" to automatically scroll serial receive views or network workspace logs to latest data; uncheck it to stay at the current history position.

HEX显示 / HEX Display

勾选"HEX显示"，数据以十六进制格式显示。
Check "HEX Display" to show data in hexadecimal format.

循环发送 / Auto Send

勾选"循环发送"并设置间隔（毫秒），数据会定时自动发送。
Check "Auto Send" and set interval (ms) to send data automatically.

快捷发送 / Quick Send

中文：界面左侧有快捷发送区域，可预设常用指令，一键点击发送。

English: Quick send panel on the left side allows preset commands with one-click sending.

  • 点击 + 按钮添加新指令 / Click + button to add new command
  • 右键点击按钮可编辑、删除或调整顺序 / Right-click button to edit, delete or reorder
  • 支持文本和HEX格式 / Supports both text and HEX format
  • 可选择是否追加换行符 / Option to append newline
💡 提示 / Tip: 快捷发送配置会自动保存，下次启动时恢复。
Quick send configuration is automatically saved and restored on next launch.

关键词高亮 / Keyword Highlight

中文：在接收区可以设置关键词高亮，方便快速识别重要信息。

English: Set keyword highlighting in receive area to quickly identify important information.

  • 勾选"高亮"启用功能 / Check "Highlight" to enable
  • 点击"设置"按钮配置高亮规则 / Click "Settings" to configure rules
  • 可自定义前景色和背景色 / Customize foreground and background colors
  • 默认高亮 OK (绿色)、ERROR/FAIL (红色) / Default highlights: OK (green), ERROR/FAIL (red)
